%{
  title: "Read page-view counts without tracking readers",
  summary: "Publishing dashboards now include first-party, cookie-free page-view analytics."
}
---

The Analytics dashboard now shows page views, the most viewed paths, and a country-level map for the last 7, 30, or 90 days. Gesttalt records only the publication, path, time, and a coarse country supplied by the hosting edge. It does not set analytics cookies, use browser storage, store referrers, or collect Internet Protocol addresses and browser identifiers.
