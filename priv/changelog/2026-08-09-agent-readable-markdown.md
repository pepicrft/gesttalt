%{
  title: "Read every publication page as Markdown",
  summary: "Publications now offer clean Markdown pages and an llms.txt index for agents and other text-first readers."
}
---

Every public publication page is now available as Markdown. Agents can request `text/markdown` at the normal page address, or follow a `.md` address such as `/blog/my-post.md`. Each publication also publishes `/llms.txt`, an index of its pages, writing, and photography feed for agent discovery.

This preserves the themed website for readers while giving agents a smaller, structured representation of the same published work.
